# 공통 뷰어 화면 계약

사례 데이터와 독립적인 고정 UI다. 사용자가 명시한 화면 흐름을 유지하고 새 사례마다 화면 코드를 만들지 않는다. 문서 계약은 [JSON Schema](schemas/model-2.0.0.schema.json) 하나다. 이 문서가 설치 스킬과 개발 저장소가 공유하는 UI 지침의 정본이다.

## 고정 화면과 탐색

- 데스크톱의 가로 공간을 사용하며 문서 전체는 수직 스크롤하지 않는다. 목록·본문·표는 각각 내부 스크롤한다.
- 상단 한 바에 제목·개요/스펙/모델/참조·가져오기/내보내기를 배치한다. 제목 아래 `메뉴 이름 - 설명`을 작게 표시한다.
- 개요는 업무 정보의 연결 그림·목표·대표 사용 예·남은 판단을 보여준다. 실제 없는 관계를 추측하지 않는다.
- 스펙은 왼쪽에 범위와 전제, 공통 설계 판단, 요구사항을 순서대로 둔다. 본문은 요약/설계안/남은 결정이며 규칙·선택지·이유를 구분한다.
- 스펙·참조 검색은 화면에 표시하는 전체 본문을 대상으로 한다. 연결된 규칙·설계 선택·쟁점도 검색하며 범위와 전제·공통 판단도 포함한다. 선택 항목이 검색 결과에 남으면 유지하고, 제외되면 첫 결과를 표시한다. 0건이면 이전 본문 대신 빈 결과 안내를 보여준다. 검색어·선택·본문/목록 스크롤은 탭을 오가도 보존한다.
- 참조는 근거 자료·제작 과정·용어 안내를 왼쪽의 단일 목록에 보여주고 오른쪽에 본문을 표시한다. 별도 하위 탭은 없다.
- 모델 탐색 패널은 모델 탭에서만 표시한다. 업무 영역/확인 사항 두 방식과 전체 보기를 제공한다. 중복 확인 사항을 영역마다 복사하지 않는다.
- 확인 사항 목록에는 제목·상황 등의 키워드 검색과 전체/확인 기록 있음/미확인 상태 필터를 제공한다. 검색어의 각 단어를 함께 찾으며 결과 수와 빈 결과를 알려준다. 검색·필터는 현재 확인 사항·ERD·카메라를 바꾸지 않는다. 선택 항목이 검색 밖에 있으면 알리고, 검색어·필터·목록 스크롤은 탐색 방식이나 상단 탭을 오가도 유지한다.
- 각 탭의 탐색과 ERD 외에 중복 이동 버튼·모달·접기·SQL·검증 전용 탭을 만들지 않는다. 내부 참조는 코드: 제목의 텍스트이고 외부 원문 URL만 링크다.

## ERD와 상세

모든 통합·전용 모델을 전체 보기에서 표시한다. 업무 영역/확인 사항 선택은 직접 관련 모델과 그 모델이 참조하는 한 단계의 연결 대상만 표시한다. 필요한 연결을 실제 관계에서 계산하고 보이는 모델 간 관계를 보존한다.

수평 배치를 우선하되 가까운 관계를 묶고 빈 공간·긴 연결선·겹침을 줄이는 후보를 선택한다. ERD에는 업무 이름·ID와 PK/FK만 표시하고 관계 코드는 선에 표시하지 않는다. 속성 전체는 오른쪽 속성 탭에서 읽는다. 캔버스의 작은 범례와 참조의 용어 안내에서 PK/FK와 1·0..1·0..N·1..N의 뜻을 설명한다. 선택한 모델과 직접 연결된 선을 강조하고 확인 사항에 속한 모델·관계도 구별한다. 선에 REL-N 코드를 다시 표시하지 않는다.

새 범위는 처음에 전체 구조가 맞도록 배율을 계산한다. 같은 범위에서 모델을 선택해도 SVG·배율·위치는 유지한다. 이동은 팬/줌·화면 맞춤·전체 보기로 명시적으로 조작한다. 캔버스 드래그에서 텍스트를 선택하지 않는다. 미니맵은 독립적으로 열고 닫고 클릭한 구역으로 이동한다.

새 영역의 배치 도중 기존 범위로 돌아가거나 배치 실패 후 캐시된 범위로 돌아가도 실제 SVG를 다시 표시한다. 캐시 객체가 같다는 이유만으로 DOM 부착을 생략하지 않는다. 늦게 끝난 배치가 현재 선택을 덮지 않으며 카메라와 포커스 보존도 함께 지킨다.

오른쪽은 속성/설명 두 탭이다. 설명은 선택한 확인 사항의 상황·기대 동작·실제 결과를 먼저, 모델의 역할·설계 선택·업무 규칙·관계 이유·남은 판단·근거를 구분해서 표시한다. 가져오기 자체를 실제 실행으로 표시하지 않는다. 결과 누락은 미확인이고 실패와 다르다. 다른 확인 사항을 고르면 설명의 시작 부분을 보여준다. 같은 확인 사항의 속성/설명이나 상단 탭을 오갈 때는 기존 스크롤을 복원한다. 숨긴 패널에서 측정한 0으로 이전 스크롤을 덮지 않는다.

모델 설명은 선택 이유·선택안·대가를 짧게 조합한다. 전체 선택지의 이점·비용·판단 기준·재검토 조건은 스펙에 보존하며 모델마다 긴 비교 카드를 복제하지 않는다. 확인 사항을 선택하면 명시적으로 연결된 규칙과 관련 요구사항의 판단을 우선하고 현재 화면의 관계 이유만 설명한다. 공통 판단과 모델 고유의 위험·남은 질문은 유지한다. 연결을 지키는 조건·보장 위치는 속성 탭의 연결 조건에서 모두 읽을 수 있다. 원문을 자르거나 새로운 요약 문장을 데이터에 중복 저장하지 않는다.

## 크기와 샘플

양쪽 패널 경계는 드래그·방향키·Home/End·Enter/더블클릭으로 조절한다. 중앙 공간과 양쪽 최소 너비를 지키고 모델 선택과 탭 전환에서 사용자 크기를 유지한다. 사용자가 정한 선호 크기와 현재 공간에 적용한 크기를 분리한다. 창을 줄였다 늘리면 양쪽 패널과 드로어 모두 원래 선호 크기로 복원한다. separator 역할·방향·범위·현재 값·조절 대상·읽을 수 있는 단위를 제공한다.

샘플은 중앙 하단에서 위로 여는 드로어 하나다. 기본은 닫힘이며 도구 모음에서 열고 닫는다. 위쪽 경계에서 세로 높이를 조절하고 ERD 일부를 남긴다. 내부 가로/세로 스크롤·고정 머리글·모든 값과 원래 ID·확인 행 강조를 제공한다. 정확히 연결된 참조는 업무용 이름을 함께 읽을 수 있게 한다. 이름이 없는 계정·주문·판매 항목도 `display_attributes`로 업무 식별 속성 조합을 명시할 수 있다. 전체 FK 조합의 타입과 값이 같은 데이터셋의 한 부모 행에 정확히 대응할 때만 보조 설명을 붙인다. 한 단계의 연결을 풀어 상품 이름+옵션 등으로 읽고, 순환 참조를 따라가지 않는다. 원래 ID는 보존한다. 미제공·빈 문자열·NULL·false·0을 구별하고 자동으로 같은 빈 칸으로 바꾸지 않는다.

ERD 범위와 예시 데이터셋은 별도의 일시 상태다. 확인 사항은 그 항목에 지정된 데이터셋을 사용한다. 업무 영역·전체 보기로 바꿔도 현재 데이터셋과 해당 모델/데이터셋의 표 스크롤을 유지한다. 여러 데이터셋이 있으면 드로어에서 이름을 읽고 명시적으로 선택할 수 있다. 확인 사항에서는 지정된 예시로 고정하며 다른 예시의 값에 기존 확인 결과나 행 강조를 붙이지 않는다. 범위를 넓히면 확인 사항 자체의 결과·강조는 해제하되 데이터는 유지한다.

드로어와 미니맵 조작·패널 크기 변경은 ERD 카메라를 바꾸지 않는다. 숨겨진 표의 스크롤을 잘못 저장하지 않는다. 드로어 Escape와 닫기는 열기 버튼으로 포커스를 돌린다. 표의 휠·텍스트 선택을 그래프 팬/줌으로 전파하지 않는다.

드로어가 열리면 미니맵은 드로어 위로 올라가고 남은 높이에 맞춰 작아진다. 명시적인 화면 맞춤·줌 버튼·미니맵 이동과 미니맵의 보이는 영역 표시는 드로어를 제외한 ERD 공간을 기준으로 계산한다. 맞춤은 범례의 높이도 고려한다. 드로어를 열거나 높이만 조절할 때는 자동으로 팬/줌하지 않는다. 공간이 부족하면 조작 힌트와 범례를 잠시 숨겨 겹침을 줄이고 공간이 늘면 복원한다.

## 키보드와 의미

상단·탐색·상세 탭은 tablist/tab/tabpanel 역할과 aria-controls/aria-labelledby로 연결한다. 선택한 탭은 aria-selected, ERD 모델은 업무 이름과 aria-pressed를 제공한다. 탭의 방향키·Home/End 및 모델의 Enter/Space 선택을 지원한다. 샘플 스크롤 영역은 명시적으로 포커스 가능하고 전체 샘플과 스크롤 방향을 안내한다. 미니맵의 열림 상태·조절 대상과 크기 조절 경계의 의미도 전달한다. 접근성 복구를 이유로 화면에 불필요한 버튼이나 설명 카드를 늘리지 않는다.

## 파일과 유지보수

빈 뷰어는 직접 작성·스킬 생성·동료 공유를 안내한다. 업무 데이터가 내장되어 있지 않고 새로고침하면 빈 화면이다. 브라우저 저장소와 서버에 업무 데이터를 자동 저장하지 않는다.

가져오기는 엄격한 JSON 문법·단일 스키마·참조·모든 데이터셋·결과 대응·크기와 깊이를 검사한다. 오류/취소/새 화면 활성화 실패는 기존 데이터와 화면을 보존한다. 최신 가져오기만 교체할 수 있고 성공 후 이전 리스너·관찰자를 해제한다.

내보내기는 전체 JSON을 보존하며 UI 선택 상태를 넣지 않는다. 경고는 기존 화면의 알림으로 읽고 새 검증 탭을 만들지 않는다.

실제 브라우저에서 1366×768 및 넓은 화면의 간격·잘림·드래그·미니맵 좌표를 확인하는 것은 Node 구조 검사와 별개다. 브라우저 접근 제한을 다른 경로로 우회하지 않으며 미수행 검사를 통과로 보고하지 않는다.

유지보수 시 이 지침을 검사 목록으로 사용한다. JSON 계약 검사, UI 상태 회귀 검사, 실제 브라우저 시각 검사는 각각 별개다. 회귀 검사는 새 사례에서도 같은 행동을 확인하고 패키징의 필수 관문으로 실행한다. 범례·연결선 강조·본문 검색·선호 크기 복원처럼 데이터 스키마에 없는 사용성도 보존한다.
